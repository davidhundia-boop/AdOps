# Campaign Optimization Tool

Super simple app: **one click to open**, drop your files, set KPIs, run optimization, download the report.

## How to open (no terminal)

1. **Double-click**  
   **`Open Campaign Optimizer.vbs`**  
   (in the `campaign-optimizer` folder)

2. Your browser opens with the app. No command prompt.

3. **First time only:**  
   If Python or dependencies aren’t set up yet, double-click **`Open Campaign Optimizer.bat`** once (a terminal will open and install things, then the app opens). After that, use the **.vbs** file for a single-click, no-terminal launch.

## In the app

- **Drop or choose** the Internal Campaign Data (.xlsx) and Advertiser Performance Report (.csv).
- **Set** the ROI column letters and KPI targets (defaults are filled).
- Click **Run Optimization**.
- See the summary and click **Save Optimization Report** to download the Excel file.

All processing stays on your machine.
