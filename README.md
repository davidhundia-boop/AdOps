# AdOps — Campaign Optimizer

Digital Turbine preload campaign optimization: upload internal + advertiser data, set KPI goals, get a color-coded Excel with bid and daily-cap recommendations.

## Run locally

```bash
cd campaign-optimizer
pip install -r requirements.txt
streamlit run app_streamlit.py
```

Or double-click **`campaign-optimizer/Open Campaign Optimizer.vbs`** (Windows).

## Deploy to the cloud

See **[DEPLOY.md](DEPLOY.md)** for step-by-step deployment to Streamlit Community Cloud.

**Quick reference:** Main file path = `campaign-optimizer/app_streamlit.py`, use the repo root `requirements.txt`.
